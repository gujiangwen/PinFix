# 隐私与权限

本文描述当前源码的行为，而不是第三方 SightLoop 服务的隐私政策。

## 数据与处理

| 数据 | 用途 | 去向 |
| --- | --- | --- |
| 页面 URL、标题、元素与文本 | 生成修复提示词和问题上下文 | 用户复制到剪贴板，或发送到已连接服务 |
| 元素选择器、尺寸、源码标记 | 定位标注元素 | 同上 |
| 用户填写的问题与反馈 | 描述修复需求 | 同上 |
| 最近最多 10 条页面错误 | 为已连接服务提供诊断上下文 | 提交问题时发送到该服务 |
| 服务源、访问令牌、更新时间 | 发现和复用 SightLoop 连接 | 扩展本地存储，最多 12 条 |

PinFix 没有遥测、广告、使用分析或第三方账户系统，不会在构建时嵌入服务地址或凭据。提示词模式不会主动把标注发送给远程服务。

复制到剪贴板或提交给服务的内容可能包含页面敏感信息，操作前请检查。接入服务后，其数据的保存、训练和删除规则由该服务决定。

## 权限用途

| Manifest 权限 | 用途 |
| --- | --- |
| `activeTab`、`tabs` | 识别当前标签页并向其发送开始/取消标注消息 |
| `storage` | 保存和更新本地服务连接 |
| `<all_urls>` 主机权限 | 在用户访问的 HTTP/HTTPS 页面提供连接桥接和标注功能 |

内容脚本在页面加载时注册；实际标注由用户通过扩展弹窗启动。浏览器内部页、扩展商店和其他受限页面可能无法运行。

## 本地记录与删除

连接记录使用 `chrome.storage.local`，不包含在构建产物中，也没有项目提供的云同步。可在浏览器的扩展数据中清除记录，或卸载 PinFix 删除扩展本地数据。撤销服务端令牌仍需在对应服务中完成。

为了兼容现有 SightLoop 接入，配置会暂时出现在页面根元素的 `data-sightloop*` 属性中。请仅在信任目标页面及其脚本的环境中使用连接功能。
