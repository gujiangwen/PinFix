# 快速上手

30 秒走完一次标注，把问题交给智能体。

## 1. 安装

从 [v0.4.0](https://github.com/gujiangwen/PinFix/releases/tag/v0.4.0) 下载对应浏览器的压缩包，解压后加载到浏览器扩展页（开发者模式）。

## 2. 打开目标页面

普通 HTTP/HTTPS 页面即可。若页面是安装扩展前打开的，点开弹窗会自动刷新该页面以注入标注能力。

## 3. 开始标注

点工具栏的 PinFix 图标 → 「简单标注」（纯文字提示词）或「截图标注」（额外附一张带红框的上下文截图），或直接按 `Alt+Shift+P`（等价于简单标注）。光标变成十字，页面进入标注态。

## 4. 选中问题元素

- **单击**：选中一个元素
- **拖拽**：框选一个区域
- **先选中文字再点击**：标注选区文本

选中后会弹出描述框；提交后自动回到标注态，可连续标注多个问题，`Esc` 退出。

## 5. 描述问题

第一行写问题，第二行（可选）写期望：

```text
底部空白太多
期望：图表区域占满剩余空间，不留死空白
```

按 `Enter` 提交，`Shift+Enter` 换行，`Esc` 取消。

## 6. 交付给智能体

**提示词模式**（默认）：点「复制提示词」，粘贴给 Claude / Cursor / Codex 等。用「截图标注」发起时，提示词与带红框的截图会一起进剪贴板，直接粘贴即可。

**SightLoop 模式**：设置页填好服务地址与令牌后，标注会提交为问题工单，在页面上跟踪修复进度。

## 标注输出长什么样

```text
请定位并修复以下前端页面问题：
- 问题：底部空白太多
- 期望：图表区域占满剩余空间，不留死空白
- 页面：交易记录 (https://example.com/trades)
- 源码：frontend/src/views/PerformanceCharts.vue:42
- 元素：div.charts-body.mode-split
- 组件链：TradeRecords.vue > PerformanceCharts.vue
- 位置：100,200 1751×723
- 文本：待核对 81 笔
- 布局：视口 1920×1080 | 元素 1751×723 | display:flex | 父容器 1775×785
```

「截图标注」时截图随提示词一起进入剪贴板，红框即问题区域。智能体拿到这段，配合截图，基本一步定位。

## 常用设置

弹窗右上角 ⚙️ 或右键扩展图标 → 选项：

- **SightLoop 接入**：服务地址 + 令牌
- **快捷键**：显示当前组合键（修改去浏览器扩展快捷键页）

截图没有开关：需要图就用弹窗里的「截图标注」入口。

## 快捷键一览

| 操作 | 快捷键 |
| --- | --- |
| 开始/取消标注 | `Alt+Shift+P` |
| 确认元素 / 提交 | `Enter` |
| 描述中换行 | `Shift+Enter` |
| 调整候选元素层级 | `↑` / `↓` |
| 取消 | `Esc` |
