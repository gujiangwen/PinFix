PinFix 设置

面向智能体的前端页面标注扩展

快捷键

Alt+Shift+P

浏览器不允许扩展自行修改全局快捷键。复制 chrome://extensions/shortcuts 并粘贴到地址栏，在打开的页面中修改。

SightLoop 接入

在此填写并保存即可，无需跳转。保存后所有页面都会使用此连接； 也可以让页面通过 window.__SIGHTLOOP__ 或 data-sightloop 自行声明连接。

关于

PinFix 是面向智能体的 Web 前端页面标注扩展。选中元素、文字或区域，生成包含页面 URL、源码位置、选择器、尺寸和文本的修复提示词；「截图标注」会额外截取以问题元素为中心、带红框的截图一并交付。
